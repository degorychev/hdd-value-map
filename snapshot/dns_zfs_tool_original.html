HDD value map for ZFS

Открываешь эту страницу в браузере, подгружаешь HAR-экспорты DNS и Regard, выбираешь схему ZFS и количество дисков, а дальше получаешь графики, таблицу и цену за полезный терабайт.

Работает локально, без сервера
Поддержка `mirror`, `raidz1`, `raidz2`, `raidz3`, `stripe`
Можно объединять несколько HAR и магазинов
Plain HTML-страница не может сама ходить на `dns-shop.ru` с подставленными cookies: мешают CORS и антибот. Поэтому основной режим здесь через HAR-файлы, а для live-сбора ниже есть генератор скрипта для DevTools на самой странице DNS.
Для полностью честной выборки желательно экспортировать все страницы каталога. `www.dns-shop.ru-pages.har` выглядит как полный проход по страницам DNS, а `www.regard.ru.har` уже содержит API-список Regard с пагинацией.
